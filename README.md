# Simple Brick Breaker

A classic 2D brick breaker arcade game built with vanilla HTML5, CSS, and JavaScript canvas.

## Features

- Lightweight and dependency-free (single HTML file)
- Smooth paddle and ball physics with variable angle bounce
- Scoring and win/game over detection
- Responsive canvas sizing
- Simple keyboard controls

## How to Play

### Controls
- **Move Left**: `Left Arrow` (`←`) or `A`
- **Move Right**: `Right Arrow` (`→`) or `D`
- **Restart Game**: `Space` (when game is over or won)

### Objective
Hit all the bricks using the paddle and ball without letting the ball fall past the paddle!

## Getting Started

No build tools or server required.

1. Clone or download this repository.
2. Open `index.html` directly in any modern web browser.
